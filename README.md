# ClinicCare - Đề 8: Hệ thống Quản lý Phòng khám / Bệnh viện

Bài thực hành học phần **Triển khai và Quản trị Hệ thống Phần mềm**.

## 1. Chức năng hệ thống

Website quản lý ba nhóm nghiệp vụ chính:

- Quản lý bệnh nhân: thêm, xem, sửa, xóa.
- Quản lý bác sĩ: thêm, xem, sửa, xóa.
- Quản lý lịch khám: đặt lịch, cập nhật và xóa lịch khám.
- Kiểm tra tránh trùng bác sĩ, ngày và giờ khám.

## 2. Công nghệ sử dụng

- Python Flask + Gunicorn
- PostgreSQL 17
- pgAdmin 4
- Nginx Reverse Proxy
- Prometheus
- Grafana
- postgres_exporter
- nginx-prometheus-exporter
- cAdvisor
- Blackbox Exporter
- Loki
- Promtail
- Docker Engine
- Docker Compose
- GitHub

## 3. Môi trường triển khai

Hệ thống được triển khai trên:

- Ubuntu Linux
- Docker Engine
- Docker Compose Plugin

Kiểm tra Docker:

```bash
docker --version
docker compose version
docker ps
EDF
